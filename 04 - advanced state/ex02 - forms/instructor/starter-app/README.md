# Lesson 16 Starter App

The starting point for lesson 16: the finished lesson 15 app. The plan is shared through `StudyPlanContext`, and Home, Study Steps and Plan all read it. This lesson adds a form that saves the plan as a named study session.

## Run it

Start the backend first, in its own terminal:

```bash
cd ../backend
node server.js
```

Then, in a second terminal:

```bash
npm install
npm start          # press w to open it in the browser, or open your development build
```

The app's config and dependencies are unchanged since lesson 13, so the development build you already have still works.
